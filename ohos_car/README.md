# ohos_car — 小车控制项目文档

## 概述

本项目用于对 **UnionPi Whale 小车底盘** 进行运动控制。程序通过 **TCP 端口 8080** 接收文本指令，结合 **IMU 姿态传感器** 实现闭环控制，最终通过串口将控制帧发送给底盘驱动器。

---

## 硬件连接

| 外设 | 串口设备 | 默认波特率 | 说明 |
|------|---------|-----------|------|
| 底盘 (Chassis) | `/dev/ttyUSB0` | **115200** | 接收运动控制指令 |
| IMU (姿态传感器) | `/dev/ttyUSB2` | **9600**(初始) → 自动扫描 | 提供航向角/加速度数据用于闭环控制 |

> IMU 波特率自动扫描顺序（`main.c:12`）：
> `115200 → 2400 → 4800 → 9600 → 19200 → 38400 → 57600 → 230400 → 460800 → 921600`
> 程序会从索引 0（115200）开始逐档尝试，与传感器通信成功即停止。

---

## 架构：四线程模型

| 线程 | 函数 | 职责 |
|------|------|------|
| 线程1 (输出) | `_serial_output_task` | 周期向底盘发送控制帧（mode=1/3 每 50ms，其余每 300ms） |
| 线程2 (IMU输入) | `_serial_IMU_input_task` | 读取 IMU 数据（航向角、加速度等） |
| 线程3 (TCP) | `_tcp_server_socket` | 监听端口 8080，解析文本指令 |
| 线程4 (底盘输入) | `_serial_input_task` | 底盘状态回读 |

## 控制指令大全

所有指令通过 **TCP 端口 8080** 发送文本字符串（自动去除 `\r\n`）。

### 2.1 基本运动指令（数字）

输入数字立即执行，`mode_flag=0`（普通模式）。

| TCP 指令 | 动作 | vel(速度) | yaw(偏航) | ang(角速度) |
|----------|------|-----------|-----------|-------------|
| `1` | **前进** | +20 | 0 | 0 |
| `2` | **后退** | -20 | 0 | 0 |
| `3` | **原地左旋转** | 0 | 0 | +20 |
| `4` | **原地右旋转** | 0 | 0 | -20 |
| `5` | **右前平移（斜向）** | +200 | +200 | 0 |
| `6` | **左转前进（左偏）** | +20 | -20 | 0 |
| `7` | **快速前进** | +200 | 0 | 0 |

### 2.2 复合模式指令（英文）

| TCP 指令 | 模式 (mode_flag) | 说明 |
|----------|-----------------|------|
| `forward` | mode=2 | **保持直线前进** — 利用 IMU `cumulativeZAngle` PID 闭环纠偏，死区 ±2°，自动保持初始航向 |
| `stop` | mode=0 | **停止** — vel=0, yaw=0, ang=0，退出复合模式 |
| `square` 或 `square 0.5` | mode=1 | **走方形轨迹** — 走完 4 条边后自动循环；可选参数为**边长(米)**，默认 0.1m |
| `circle` 或 `circle 0.5` | mode=3 | **走圆形轨迹** — 持续圆弧运动；可选参数为**半径(米)**，默认 0.1m |

> ⚠️ 有效载荷上限：若边长为 0.3m，实际约承载 0.1kg，超出可能导致驱动不足。

## 复合模式内部逻辑详解

### square（走方形，mode=1）

**状态机：**
```
IDLE → STRAIGHT(直行) → TURNING(90°转向) → STRAIGHT → TURNING → STRAIGHT → TURNING → STRAIGHT → TURNING
    ↑                                                                                                       │
    └──────────────────────────────────── 完成 4 边，自动循环 ───────────────────────────────────────────────┘
```

**直行阶段**（`square_walk.c:127-162`）：
- base_speed = 50 (由 `square_walk_init` 传入)
- 目标航向角固定，通过 `fAngle[2]` (IMU Yaw) 实时闭环
- ⚠️ **死区 = 100°，超出才 PID 纠偏**（注释写 3°，代码是 100°，疑似缺陷，建议开发时改为 3°~5°）

**转向阶段**（`square_walk.c:165-178`）：
- vel=0 原地旋转，ang = ±100 (0.01°/s)，方向由误差正负决定
- ⚠️ **转向完成阈值 = 40°**（注释写 2°，代码是 40°——40° 的容差意味着实际走不出方形，建议改为 2°~5°）
- 转完后 `current_side++`，满 4 边自动循环

### circle（走圆形，mode=3）

**逻辑：**
- 根据走过的弧长递增目标航向角 `target_yaw = target_yaw + delta_angle`
- PID 实时跟踪目标航向，输出 `ang = turn_speed + pid_output * 100`
- `turn_speed` 由半径和速度自动计算：`angular_velocity = speed / radius`
- base_speed = 50mm/s，默认半径 0.1m 时 turn_speed ≈ 28647 (0.01°/s)

### forward（直线前进，mode=2）

- 记录开始时的 `cumulativeZAngle` 作为目标
- 每 300ms 判断：航向在目标 ±2° 内 → 直行(vel=20)；偏差 >0 且 ≤180° → 右转纠偏(ang=-10)；否则左转纠偏(ang=10)

## 底层串口协议

所有指令最终通过 `ChangeSendType(int vel, int yaw, int ang)` 组装为 12 字节控制帧，通过串口 `/dev/ttyUSB0`（波特率 **115200**）发送给底盘。

### 帧格式

```
偏移  字节数   值                           说明
0     1       0x0A                         帧头0
1     1       0x0C                         帧头1
2     1       0x06                         数据长度 (固定6)
3     1       0x00                         保留
4     1       0x02                         响应ID
5     1       vel[7:0]    (低8位)           速度低字节
6     1       vel[15:8]   (高8位)           速度高字节
7     1       yaw[7:0]                     偏航低字节
8     1       yaw[15:8]                    偏航高字节
9     1       ang[7:0]                     角速度低字节
10    1       ang[15:8]                    角速度高字节
11    1       xor                          异或校验
```

**异或校验计算：**
```c
xor = data_length ^ response_id ^ data[0] ^ data[1] ^ data[2] ^ data[3] ^ data[4] ^ data[5]
// 即: 0x06 ^ 0x02 ^ vel低8位 ^ vel高8位 ^ yaw低8位 ^ yaw高8位 ^ ang低8位 ^ ang高8位
```

### 参数含义

| 参数 | 类型 | 说明 |
|------|------|------|
| `vel` | 有符号16bit | 速度：正=前进，负=后退 |
| `yaw` | 有符号16bit | 偏航角度：正=右偏，负=左偏 |
| `ang` | 有符号16bit | 旋转角速度 (单位 0.01°/s)：正=左转，负=右转 |

## 上电/下电与模式切换

### 上电 Power(1) — 7字节帧（write 12字节，后5字节填充0）

```
0A 0C 01 00 01 01 01 00 00 00 00 00
```

### 下电 Power(0) — 7字节帧

```
0A 0C 01 00 01 00 00 00 00 00 00 00
```

### 速度-角速度模式切换

```
0A 0C 01 00 05 00 04
```
（仅 7 字节，无填充，由 `write(fd_chassis, switch_mode_cmd, 7)` 发送）

## 启动流程

1. 打开底盘串口 `/dev/ttyUSB0` (115200)
2. 打开 IMU 串口 `/dev/ttyUSB2` (9600)
3. 关闭并重新从 115200 开始**自动扫描** IMU 波特率，连接姿态传感器
4. PID 控制器初始化 (`PID_init`)
5. 创建 4 个线程（底盘输出 / IMU输入 / TCP服务 / 底盘输入）
6. 底盘输出线程启动 → **上电** `Power(1)`
7. 底盘输出线程启动 → **切换速度-角速度模式** `0A 0C 01 00 05 00 04`
8. 进入 `while(1) sleep(10)` 主循环，等待 TCP 指令

## 使用示例

```bash
# 通过 TCP 连接小车（默认端口 8080）
nc <小车IP> 8080

# 发送指令
1                # 前进
2                # 后退
3                # 原地左旋转
4                # 原地右旋转
5                # 右前平移
6                # 左转前进
7                # 快速前进
stop             # 停止
forward          # 保持直线前进
square           # 走方形（默认边长 0.1m）
square 0.5       # 走方形，边长 0.5 米
circle           # 走圆形（默认半径 0.1m）
circle 1.0       # 走圆形，半径 1.0 米
```

## ⚠️ 开发注意事项

1. **square_walk 转向阈值** (`square_walk.c:94`)：注释写 2°，代码是 `40.0f`，导致 90° 转向只转到 50° 就判定完成，**建议改为 `2.0f` ~ `5.0f`**
2. **square_walk 直线死区** (`square_walk.c:132`)：注释写 3°，代码是 `100.0f`，导致几乎不纠偏，**建议改为 `3.0f` ~ `5.0f`**
3. **Power() 填充不足**：填了 7 字节但 write 12 字节，后 5 字节为 `0` 填充，如需严格协议应补充完整
4. **mode=0 默认无锁保护**：多线程访问 `vel_temp/yaw_temp/ang_temp/mode_flag` 时 TCP 接收加了锁，但输出线程`_serial_output_task` 的 `pthread_mutex_lock(&lock)` 被注释掉了
